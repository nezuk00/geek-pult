# Гик-пульт

Закрытая редакция Telegram: RSS и публичные Telegram-ленты, отбор, русские посты с существующими изображениями, история и отправка через Bot API.

## Запуск пользователем

1. Откройте свою закрытую панель и войдите в ChatGPT.
2. В разделе «Настройки» укажите @имя канала и токен бота из [BotFather](https://t.me/BotFather).
3. Бот должен быть администратором канала с правом публикации. Нажмите «Проверить и сохранить канал». При смене канала токен можно оставить пустым: используется уже подключённый бот. Подключение остаётся на паузе.
4. Оставьте компьютер и Codex включёнными: редактор запускается автоматизацией Codex каждые 2 часа. При необходимости снова войдите в панель.

Подключение проверяет бота, тип канала и право публикации; тестовое сообщение не отправляется. Пауза немедленно запрещает следующие автоматические отправки. Кнопка ручной публикации доступна отдельно, но также соблюдает интервал 2 часа.

Адрес канала задаётся владельцем в настройках и проверяется перед публикацией. Пауза расписания и пауза панели сохраняются до явной команды возобновить. Для фонового запуска нужны включённая автоматизация Codex и включённый автопилот панели.

## Что делает редактор

Сборщик сохраняет заголовки, короткие фрагменты и исходные ссылки в D1, отбирает аниме и мангу, отбрасывает новости старше 36 часов, будущие даты и похожие заголовки. Для интервью и материалов о производстве окно — 30 дней: старые факты обязательно помечаются «Из интервью» или «Из архива». Предварительная оценка в интерфейсе вычисляется правилами. Полноценный анализ, проверку первоисточника, поиск смысловых повторов и русский пересказ выполняет редактор по своей инструкции. Локальную `AUTOPILOT.md` не добавляйте в Git: для примера используйте `AUTOPILOT.example.md`. Отдельный платный API генерации не используется.

В настройках можно задать тему канала. Редактор добавит отдельный поиск по этой теме в Google News RSS; включение и отключение поиска доступно на вкладке «Источники». Найденные записи поступают в обычную ленту и требуют проверки редактором. Это поиск публикаций по теме, а не оценка надёжности издателя: для поста по-прежнему нужна проверяемая статья новостного сайта.

Не больше одного поста за цикл и не чаще одного за 2 часа. Если достойных подтверждённых новостей нет, цикл пропускается. Источники с ошибками не останавливают остальные. Из Telegram читаются только доступные публичные веб-ленты; приватные каналы и личный аккаунт не используются. Недоступность каждой ленты явно отображается в панели.

Каждый выпуск — JPEG/PNG и подпись до 1024 символов вместе со ссылкой на новостной сайт. Telegram-источники остаются внутри редакции: для них редактор находит подтверждающую статью. Сервер запрещает Telegram-ссылки в подписи. Картинки берутся из статьи или находятся редактором в интернете, проверяются визуально и никогда не генерируются. В панели сохраняются URL картинки, страница происхождения, внутренняя заметка проверки и при необходимости публичный автор. Если достойной картинки или подтверждающей статьи нет, выпуск пропускается. Перед отправкой сервер скачивает и проверяет размер и формат изображения; автоматической замены на текстовый пост нет.

Токен шифруется AES-GCM с отдельным серверным SETTINGS_KEY. В API состояния секрет не возвращается. Чтение и действия защищены входом ChatGPT и закрытым доступом Sites. Блокировка отправки и интервал хранятся в базе. При неопределённой доставке запись получает статус uncertain и не отправляется повторно автоматически: проверьте канал вручную.

## Разработка

Node 22.13+; npm ci; npm run dev. На Windows при проблеме системного npm shim используйте Node с абсолютным путём к npm-cli.js. Приложение использует Vinext/React, Cloudflare Workers и D1. Локальный вход — /signin-with-chatgpt?return_to=/.

Конфигурация Sites находится в локальном `.openai/hosting.json` и не входит в репозиторий: она содержит идентификатор конкретного размещения. Без неё dev-сборка использует локальную базу D1 и не копирует hosting-конфигурацию в артефакт. Платформу Sites настраивайте отдельно для своего размещения.

В .env задайте SETTINGS_KEY: base64 от 32 случайных байт. Для hosted-среды секрет задаётся через Sites; он не хранится в Git. Не меняйте ключ после сохранения токена без повторного подключения бота.

Миграции: npm run db:generate. После сборки примените новые миграции локально через Wrangler D1 с конфигурацией dist/server/wrangler.json и каталогом .wrangler/state. Production-миграции применяет Sites при публикации.

Проверки: node node_modules/typescript/bin/tsc --noEmit; node --test tests/core.test.mjs; npm run build. Тесты используют SQLite и подменённый Telegram, реальных сообщений не отправляют. Проверены RSS/Atom и Telegram, свежесть, дубли, частичный отказ источников, шифрование, параллельная отправка фото, неопределённая доставка, пауза, ссылки на сайты, извлечение изображений и отказ до отправки при некорректном фото. WebMCP зарегистрирован с feature detection и доступен в браузере Codex.

## Источники и стиль

- [Anime Corner](https://animecorner.me/feed/) — новости, необычные тайтлы, интервью с создателями.
- [Sakuga Blog](https://blog.sakugabooru.com/feed/) — аниматоры и истории производства.
- Публичные Telegram-ленты ru2chvg, nerds, gcapixel, pekagame, stopgamenews — только материалы об аниме и манге.

Рубрики: «Новости», «Что смотреть», «Споры фандома», «Факты и закулисье». Приоритет — конкретная интересная история, а не очередная дата трейлера. Короткий русский пост, понятный крючок в заголовке и уместная ирония. Споры в X проверяет редактор по исходным публичным сообщениям и статье сайта; сам RSS-сборщик X не читает. Утверждения о масштабах конфликта не выдумываются.

История старого канала сохраняется; старые игровые черновики не допускаются к отправке. Смена канала проверяет права текущего бота и не отправляет тестовый пост.

Публикация: [официальная документация Telegram Bot API](https://core.telegram.org/bots/api#sendphoto).
