# Участие в разработке

Спасибо за интерес к проекту. Небольшие исправления и улучшения можно предлагать через GitHub Issues или Pull Requests.

## Перед отправкой изменений

- Убедитесь, что в diff нет `.env`, токенов Telegram, адресов личных каналов и локального `AUTOPILOT.md`.
- Сохраняйте ручное подтверждение перед реальной отправкой и защиту от повторной отправки при неизвестной доставке.
- Не ослабляйте проверку адресов новостных сайтов и источников изображений без отдельного объяснения в PR.
- Запустите линтер, проверку типов, тесты и production-сборку.
- Опишите изменение и укажите команды и результаты проверок.

## Локальный запуск

Требуется Node.js 22.13 или новее. Установите зависимости командой `npm ci`, скопируйте `.env.example` в `.env`, задайте локальный `SETTINGS_KEY` и запустите `npm run dev`. Никогда не отправляйте `.env` в PR.
