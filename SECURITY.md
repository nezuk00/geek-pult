# Сообщение об уязвимости

Не публикуйте сведения об уязвимостях, активные токены, ключи или данные каналов в открытом issue.

Если в настройках репозитория включены GitHub Security Advisories, отправьте приватное сообщение через вкладку Security → Advisories. Если приватные advisories недоступны, свяжитесь с владельцем репозитория напрямую и передайте только минимальные сведения, необходимые для воспроизведения.

Перед выпуском исправления отзовите раскрытые Telegram-токены через BotFather и замените ключи шифрования согласно плану восстановления. Удаление секрета из последнего коммита не удаляет его из истории; раскрытые ключи нужно считать скомпрометированными.
